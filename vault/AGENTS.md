# Vault guide for AI agents

This is a personal Obsidian vault. Before reading or writing, read `Meta/protocol.md`. It explains the folders, what you may do, and the note rules. `Meta/vault-map.md` maps folder roles to names; `Meta/user-profile.md` has the user's terms and the work/home boundary.

If you are Claude Code, `CLAUDE.md` and `.claude/` take precedence.
