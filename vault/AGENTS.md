# Vault guide for AI agents

This is an Obsidian vault run with minions. Before reading or writing, read `Meta/protocol.md`. It explains the folders, what you may do, and the note rules. `Meta/vault-map.md` maps folder roles to names; `Meta/user-profile.md` has the user's terms, task manager and any boundaries.

If you are Claude Code, `CLAUDE.md` and `.claude/` take precedence.
